Presentation day for the 2024 Gen AI SW Development Bootcamp, held over Google Meet.

Highlights from our eight-week bootcamp on Gen AI and the Future of Software Development, organized by Computer Science for Equity & Beyond (CSEB) and VC.in.Taiwan. Under the guidance of Coach Alwin Lin, the course demystified machine learning concepts and introduced high school students to large language models like ChatGPT.

Learning outcomes

  • Mastered machine learning basics with Teachable Machine
  • Learned Python and how to work with APIs
  • Built a content summarization bot with the Whisper and GPT APIs
  • Learned the fundamentals of chatbot development
  • Automated web searches and information gathering
  • Shipped a Portfolio AI project combining everything above

Week by week

Week 1: Teachable Machine & project forethought

Machine learning basics and end-to-end development, hands-on.

Week 2: APIs and basic Python

Python syntax, API calls, and speech-to-text with the Whisper API.

Week 3: Building a summary bot

A bot that transcribes YouTube videos and writes Markdown summaries with GPT.

Week 4: Preparing the web search bot

Web scraping with requests and BeautifulSoup, plus LangChain tools.

Week 5: Coding the web search bot

A research bot integrating scraping and API calls, hosted on Streamlit.

Week 6: Portfolio AI workshop

An AI-powered portfolio bot to help with college applications.

Weeks 7–9: Group projects

Teams built a gen-AI project of their choosing and presented to the class.

Skills acquired

  • Python proficiency, from syntax to advanced libraries
  • Practical API knowledge in real projects
  • Core machine learning concepts
  • Interactive bots with scraping, NLP, and summarization

Thanks to every participant, and to guest speaker Jainam Shah (March 8, 2024). We’re proud of what these students accomplished.
