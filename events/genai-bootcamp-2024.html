2024 · Gen AI & The Future of SW Development Bootcamp

Monday, October 21, 2024 · 7:30 PM – 8:30 PM

Workshop Archive

Presentation day 2024 — the Gen AI SW Development Bootcamp over Google Meet.

We're excited to share the highlights from our 8-week bootcamp on Gen AI and the Future of Software Development, organized by Computer Science for Equity & Beyond (CSEB) and VC.in.Taiwan. Under the guidance of Coach Alwin Lin, the course demystified machine learning concepts and introduced high school students to large language models like ChatGPT.

Learning objectives & outcomes

  • Mastered the basics of machine learning using Teachable Machine
  • Learned Python programming and how to interact with APIs
  • Developed a content summarization bot using the Whisper API and GPT API
  • Understood the fundamentals of chatbot development
  • Automated web searches and information gathering
  • Created a comprehensive Portfolio AI project combining all learned skills

Weekly breakdown

Week 1 · Teachable Machine & project forethought

Introduced machine learning basics and end-to-end development with hands-on Teachable Machine experience.

Week 2 · APIs and basic Python

Python syntax, making API calls, and processing responses using the Whisper API for speech-to-text.

Week 3 · Building a summary bot

A bot that transcribes YouTube videos and generates summaries in GitHub Markdown format using GPT.

Week 4 · Preparing the web search bot

Web scraping with requests and BeautifulSoup, plus LangChain tools for automation.

Week 5 · Coding the web search bot

A research bot integrating scraping and API calls to answer user queries, hosted on Streamlit.

Week 6 · Portfolio AI workshop

A portfolio bot powered by AI to help with students' college applications.

Weeks 7–9 · Group projects

Students worked in groups on a gen-AI project of their choosing, then presented to the class.

Skills acquired

  • Proficiency in Python, from foundational syntax to advanced library usage
  • Practical knowledge of APIs in real-world projects
  • Core machine learning concepts
  • Building interactive bots with scraping, NLP, and summarization

Thank you to all participants for their enthusiasm and hard work — and to guest speaker Jainam Shah (Mar 8, 2024). We're proud of what every student accomplished.
