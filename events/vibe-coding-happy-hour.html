Vibe Coding Happy Hour

2025 · Two-hour workshop · Virtual or in-person

Spark curiosity by having fun making games. Vibe Coding Happy Hour is a two-hour workshop that introduces K-12 students to AI-assisted game development using the Gemini CLI — hands-on building with AI-augmented understanding, organized around collaboration and play.

How it runs

  • Introduction (30 min) — what AI is, how command-line tools work, and what "vibe coding" means
  • Build (60 min) — teams of 3–5 students, each with a coach, create their first game using generation-then-comprehension: the AI writes, the students interrogate
  • Showcase (20 min) — teams demo their games and playtest each other's projects

What students walk away with

  • A game they built themselves — often their first piece of software
  • File system navigation and command-line basics
  • An intuition for autonomous AI tools and their limits
  • Technical communication skills from peer playtesting

Run it yourself

The complete curriculum — slides, coach guides, setup instructions, and live game examples — is open source, so any coach can deliver it locally.
