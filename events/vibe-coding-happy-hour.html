Vibe Coding Happy Hour

2025 · 2-hour workshop · Virtual or in-person

Workshop Archive

Spark curiosity by having fun making games. Vibe Coding Happy Hour is a 2-hour workshop that introduces K-12 students to AI-assisted game development using the Gemini CLI — hands-on experience with AI-augmented understanding, built around collaboration and play.

How it runs

  • Introduction (30 min): What AI is, how command-line tools work, and what "vibe coding" means.
  • Build (60 min): Small teams of 3–5 students, each with a coach, create their first game using AI generation followed by comprehension questions — our "generation-then-comprehension" approach.
  • Showcase (20 min): Teams demo their games and playtest each other's projects.

What students walk away with

  • A game they built themselves — often their first ever piece of software
  • File system navigation and command-line basics
  • An intuition for autonomous AI tools and their limits
  • Technical communication skills from peer playtesting

Run it yourself

The complete curriculum — slides, coach guides, setup instructions, and live game examples — is open source, so any coach can deliver it locally.
